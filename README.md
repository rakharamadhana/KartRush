# Kart Rush

A Mario Kart-style 3D kart racer made with Unity 6 (URP).

**Play in your browser:** https://rakharamadhana.github.io/KartRush/

## Controls
| Action | Keyboard | Gamepad |
|---|---|---|
| Gas / brake | W / S or Up / Down | Right / left trigger |
| Steer | A / D or Left / Right | Left stick |
| Drift (release for mini-turbo) | Space / Left Shift | A / right bumper |
| Use item | E / Left Ctrl | X / left bumper |
| Respawn | R | |
| Pause | Esc | Start |
| Autopilot (debug) | T | |

## Features
Procedural track, arcade drift physics with 3-level mini-turbo, 5 AI rivals with rubber-banding and Easy/Normal/Hard, item boxes (mushroom, banana, homing shell), minimap, title/pause/finish menus, procedurally generated sound and music (no audio files).

Open the project in Unity 6000.3; build the scene with the menu **KartRush > Build Prototype Scene**.
